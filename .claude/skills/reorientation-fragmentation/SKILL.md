# Reorientation and fragmentation

Under load grains **reorient**; that reorientation **fragments** them into orientation sub-grains;
the grains that fragment most are the **rare events**. Two classes drive everything:
`OrientationTracker` (IPF trajectories) and `FragmentationAnalyzer` (segmentation, split detection,
per-grain fragment counts). Plotting stays in `plot_postprocessing`. Env: `conda activate moose-src`
(neml2 + networkit; the detector core is pure NumPy+SciPy). Full script:
`examples/demonstrate_reorientation_fragmentation.py`.

## 1. Simulation reorientation tracking
```python
from graintrace.simulation_postprocessing import SimulationResults, FieldFileNaming
from graintrace.ipf_orientation_tracking import OrientationTracker
from graintrace import plot_postprocessing as pp

naming = FieldFileNaming(prefix="out_element_centroid", index_width=4, sep="_", suffix=".csv")
res = SimulationResults("out.csv", "mesh_out", field_naming=naming)   # real CPFE run
tracker = OrientationTracker()
tracks = tracker.simulation_grain_tracks(res, grain_ids=range(1, 11), steps=sorted(res.field_files))
pp.plot_ipf_orientation_tracking(tracks, angle_convention="mrp", output_folder="out")
```
`OrientationTracker` also has `simulation_element_tracks` (per-element fans), `experiment_grain_tracks[_by_id]`,
and `@staticmethod compose_tracks`.

## 2. Simulation fragmentation — the 1×2 figure (reorientation vs segmentation)
```python
from graintrace.fragmentation import FragmentationAnalyzer
from matplotlib import cm
import matplotlib.pyplot as plt

analyzer = FragmentationAnalyzer()
frags_df, per_elem = analyzer.grain_fragments(res, last_step, tol_deg=5.0, seg_kwargs={"gamma": 0.1})
id_colors = [cm.tab10(i % 10) for i in range(n_grains)]     # ONE color per grain, shared by panels
fig, (axL, axR) = plt.subplots(1, 2, figsize=(13, 6))
pp.plot_ipf_orientation_tracking(left_tracks, angle_convention="mrp", arrow_color=id_colors, ax=axL)
pp.plot_ipf_fragmentation_tracking(branches, angle_convention="mrp", arrow_color=id_colors, ax=axR)
```
- `arrow_color` now accepts a **per-entity color list** (one per track/branch); the start dot keeps
  its IPF color, arrows take the id color -- so a grain is cross-referenceable LEFT↔RIGHT.
- Passing `ax=` makes the plotters draw into it and **return the ax** (no save), for subplots.
- `branches = [(parent_track, [child_track, ...]), ...]`; build children from `per_elem` fragment
  means. `IPFProcessor.add_element_field_to_exodus(mesh.e, centroids, codes, "fragment_label", out)`
  writes a per-element field into a SCULPT-hex Exodus for ParaView.

## 3. Experiment split detection (FF / NF / EBSD)
```python
res = analyzer.detect_splits(nodes_a, nodes_b, d_tol=20.0, theta_tol_deg=15.0, angle_type="degrees")
# res["n_splits"], res["split_correspondences"] (parent_a, children_b, n_children) + merges/births/deaths
```
FF grain tables feed it directly; NF/EBSD reach the same detector via `analyzer.segment` (graph/Leiden)
+ `analyzer.seg_to_grain_table`. Synthetic mixed-multiplicity series (1→1/1→2/1→3) with ground truth:
`mwe_data/synthetic_split_{ff,nf,ebsd}/`, generated by `tests/synthetic_fragmentation.py`.

## 4. Rare events — the grains that split the most
```python
from graintrace import rare_criteria_selection_library as rcs
rank = frags_df.rename(columns={"grain_id": "cluster_label", "n_elements": "n"})
rare = rcs.select_highest_scalar(rank, required_cols="n_fragments", k=3, min_size=1)
```
For field-level REI, `analyzer.write_reorientation_field(res, step, "reo.csv", ref_step=...)` writes
`reorientation_deg` and feeds `IdentifyRareClusters` with the `abs_scalar_diff` metric (standalone or
combined with nye/stress).

## Gotchas
- `ori_rodrigues` is neml2 v3 MRP (misnamed), mapped via `mrp_to_matrix` — not classical Rodrigues.
- Segmentation: graph/Leiden is the default (flood over-merges). For few-grain / sub-grain data pass a
  fixed low `gamma` (~0.1); the gamma-by-percolation sweep is for large many-grain NF (CLAUDE §4).
- `detect_splits`: `d_tol` at grain scale; `theta_tol_deg` generous (~15°) since children keep diverging.
- Field-step indices are the CSV indices (non-contiguous with sync times) — index into
  `sorted(res.field_files.keys())`.
