# Grain fragmentation (split) detection: recommended parameters

`detect_fragmentation` detects one grain splitting into several between two load
steps — beyond the strictly 1-to-1 `track_grains`. Cross-step graph + connected
components (centroid distance + misorientation), classifying each lineage as
match / split / merge / birth / death. Pure NumPy+SciPy (+neml2 for orientation math).

## Model
1. candidate cross edges = each step-A grain's `top_k` nearest step-B centroids,
2. kept if centroid distance <= `d_tol` AND misorientation <= `theta_tol_deg`,
3. union graph over A and B → `scipy.sparse.csgraph.connected_components`,
4. component `(nA,nB)`: (1,1) match, (1,m>1) **split**, (n>1,1) merge, (1,0)/(0,1) death/birth.

## Minimum you must supply
- `nodes_a`, `nodes_b`: per-grain node tables (CSV) for the two steps:
  `grain_id, X, Y, Z, GrainRadius, Eul0/1/2`.
  - **FF**: use the per-step FF grain CSV directly.
  - **NF/EBSD**: segment each step's voxel data with the graph/Leiden recipe
    (`FragmentationAnalyzer.segment`) then reduce to a grain table with
    `FragmentationAnalyzer.seg_to_grain_table` (proper quaternion mean + equivalent-sphere
    radius) — all three converge on the SAME detector. See the `nf_segmentation` recipe.

## Parameters
- `d_tol`: set to grain scale. Too large chains distinct neighboring grains into one
  "complex" component.
- `theta_tol_deg`: GENEROUS (~15°) — children keep diverging across steps, so a tight
  cutoff misses the split. Different base grains stay separate via this filter, so real
  grains must be well-separated in orientation.
- `top_k`: nearest B centroids probed per A grain.

## Synthetic test data
Shipped `mwe_data/synthetic_split_{ff,nf,ebsd}/` carry a known 1→2 split
(misorientation grows past the tol across steps) with a `ground_truth.json`. They are
generated by the test helper `tests/synthetic_fragmentation.py`
(`generate_{ff,nf,ebsd}_split`) — re-run it to regenerate.
