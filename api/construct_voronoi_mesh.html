graintrace.construct_voronoi_mesh

Reconstruct FF-HEDM microstructures via NEPER Voronoi tessellation (VoronoiMeshBuilder).

class graintrace.construct_voronoi_mesh.VoronoiMeshBuilder(input_csv, output_dir, bounding_box, dim=3, weighted=False, auto_fix_bbox=False, bbox_fix_mode=None, bbox_tolerance=0.0, auto_rotate=False, rotate_angles=(0, 0, 0), rotate_convention='xyz', angle_identifier=None, orientation_descriptor='euler-bunge', orientation_active_convention=False, unit='deg', elastic_strain_identifier=None, ori_rotmat_identifier=None, strain_unit='microstrain', env=None, neper_path=None, auto_install=False)[source]

Bases: object

Reconstruct a 3D microstructure from far-field (FF) HEDM grain centroids.

Wraps NEPER (Voronoi/CVT tessellation) and optionally GMSH to turn a per-grain FF CSV (positions, Euler orientations, elastic strains) into a .tess/.msh mesh, per-grain orientation and initial elastic-strain files, and a voxelized reconstruction: the inputs for a CPFE run or a grain graph. See examples/demonstrate_farfield.py and the /ff-reconstruction skill.

build_voronoi(option='voronoi', generate_mesh=False, relative_el_size=None, morphoalgo='praxis', mesh_quality_min=0.9, tesr_size=None, CVT_iter=1000)[source]

Build a Voronoi (or Laguerre) tessellation using Neper.

Reads the input CSV (if not already loaded), validates/fixes the bounding box, runs NEPER to produce the tessellation, applies the rotation to the cell orientations and strains, evaluates the output, optionally meshes it, and writes the reformatted voxel reconstruction CSV/VTK plus the CPFE strain files.

Parameters:

  • option (str) – Tessellation seeding mode: “voronoi” (Poisson-Voronoi), “centroid”/”centroidal” (fit cell centroids to the input coordinates), or “centroidsize” (fit centroid and size, requires GrainRadius).

  • generate_mesh (bool) – If True, also generate a NEPER/GMSH tet (or tri) .msh mesh; this is a fallback only, the default CPFE mesh is SCULPT hex.

  • relative_el_size (float) – Mesh element size relative to grain size, passed to generate_mesh; defaults to 1.0 when None.

  • morphoalgo (str) – NEPER morphology optimization algorithm, e.g. “praxis”, “subplex”, or “lloyd”.

  • mesh_quality_min (float) – Minimum acceptable mesh element quality, passed to generate_mesh.

  • tesr_size (list) – Voxel raster resolution [nx, ny, nz] for the .tesr output; defaults to [20, 20, 20] when None.

  • CVT_iter (int) – Number of CVT/morphology optimization iterations.

build_graph(device='cpu', option='centroid', CVT_iter=100, morphoalgo='praxis', visualize2D=False, visualize3D=False)[source]

Build a Voronoi tessellation and convert it to a graph representation.

Runs build_voronoi (no mesh) then parses the resulting .tess into a per-cell graph via NeperTessToGraphNN, registering the loaded dataframe features on it.

Parameters:

  • device (str) – Torch device for the graph tensors, e.g. “cpu” or “cuda”.

  • option (str) – Tessellation seeding mode passed to build_voronoi: “voronoi”, “centroid”, or “centroidsize”.

  • CVT_iter (int) – Number of CVT/morphology optimization iterations passed to build_voronoi.

  • morphoalgo (str) – NEPER morphology optimization algorithm passed to build_voronoi.

  • visualize2D (bool) – If True, save a 2D rendering of the graph under output_dir/figures/gnn.

  • visualize3D (bool) – If True, save a 3D rendering of the graph under output_dir/figures/gnn.

Returns:

The per-cell graph object produced by NeperTessToGraphNN.build_cell_graph.
