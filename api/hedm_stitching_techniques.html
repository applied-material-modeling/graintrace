Per-grain cell geometry from a Neper tessellation, for HEDM stitching.

Given a set of grain centroids (one scan or a stitched accumulator), build a (Laguerre / power) Voronoi tessellation at the measured centroids, with no CVT relaxation, and read back each grain’s true polyhedral z-extent [Zmin, Zmax] and volume centroid. This replaces the equivalent-sphere z +/- GrainRadius approximation used by the region classifier for elongated / anisotropic grains.

graintrace.hedm_stitching_techniques.scan_tessellation.default_neper_env()[source]

Subprocess environment for a user-installed NEPER.

Resolves the neper binary via graintrace.neper_env (NEPER env var -> tools.json -> PATH) and puts its bin/lib directories on PATH / LD_LIBRARY_PATH so a self-built NEPER finds its GSL/OpenBLAS libs. Falls back to a plain os.environ copy when NEPER cannot be located.

graintrace.hedm_stitching_techniques.scan_tessellation.compute_cell_geometry(df, bbox, weighted=True, coord_cols=('X', 'Y', 'Z'), radius_col='GrainRadius', work_dir=None, env=None, neper_bin='neper', keep_files=False)[source]

Tessellate df’s grains inside bbox and return per-grain cell geometry.

The tessellation is a (Laguerre when weighted) Voronoi diagram of the exact measured centroids; -morphooptistop iter=0 disables CVT relaxation so cells stay anchored at the grains. Cell i corresponds to input row i (the same seed-order assumption VoronoiMeshBuilder relies on for orientation mapping).

Parameters:

  • df (DataFrame) – grain table with coord_cols (and radius_col when weighted).

  • bbox (Sequence[float]) – domain [xlo, xhi, ylo, yhi, zlo, zhi]. z should be the scan FOV window so that a cell touching the z-limit means the grain is truncated.

  • weighted (bool) – Laguerre weight = effective grain volume (4/3)*pi*r**3.

  • work_dir (str | None) – scratch dir for Neper I/O (a temp dir is used and removed if None).

  • env (dict | None) – subprocess env (defaults to default_neper_env()).

  • coord_cols (Sequence[str])

  • radius_col (str)

  • neper_bin (str)

  • keep_files (bool)

Returns:

DataFrame indexed like df with columns Zmin, Zmax, Xc, Yc, Zc, Vol.
