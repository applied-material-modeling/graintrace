graintrace.taylor

Uniaxial Taylor crystal-plasticity forward + calibration model (NEML2 v3).

A mixed-control NEML2 NonlinearSystem (cpfe_base/neml2_cpfe_calibration.i) is wrapped by neml2.pyzag.NEML2PyzagModel and driven through pyzag.nonlinear.solve_adjoint() for analytic parameter gradients.

class graintrace.taylor.UniaxialTaylorModel(factory, axial_index=2, nchunk=5, rtol=1e-06, atol=1e-08, linesearch_iter=5)[source]

Bases: Module

Differentiable uniaxial Taylor forward via a NEML2 mixed-control eq_sys.

Wraps a neml2.pyzag.NEML2PyzagModel and integrates the strain history with pyzag.nonlinear.solve_adjoint. Uniaxial loading is expressed with NEML2’s MixedControlSetup: control selects the axial component as strain-controlled (prescribed = rate); the remaining components are stress-free, and a global constraint forces target_cauchy_stress to equal the grain-mean per-crystal stress.

Run a differentiable uniaxial stress-strain simulation.

Parameters:

  • params – optional 1-D tensor of the six calibration values. If given, they are assigned to the factory (no grad) before the solve; use this for plotting a specific parameter set. Pass None to run with the factory’s current (possibly optimizer-owned) parameters so gradients flow (used during calibration).

  • d (Tensor | None) – ignored (kept for API compatibility; the axial direction is set by self.axial_index).

  • assumed_rate (float | None) – strain rate; defaults to self.assumed_rate.

  • experiment_data – dict from load_experiment_data().

  • return_state (bool) – also return the per-grain elastic strain history.

  • initial_strains – optional (n_grains, 6) initial elastic strain.

Returns:

stress_hist (npoints, 6), or (stress_hist, state_hist) where state_hist is (npoints, n_grains, 6) elastic strain.
